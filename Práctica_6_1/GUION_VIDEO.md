# Guion de video — Práctica 6.1

Duración objetivo: **1:40 a 1:55 minutos**.

**0:00–0:12**

“Esta es mi Práctica 6, un sistema para banco desarrollado con Flask, JavaScript y una base de datos SQLite. El sistema utiliza agentes especializados para validar y ejecutar las operaciones.”

**0:12–0:28**

“En el panel principal se observa el número de cuenta y los datos del cliente asociado. También se muestra el saldo de débito, la tarjeta vinculada y el crédito disponible.”

**0:28–0:52**

“En tarjeta de débito puedo realizar depósitos, retiros y transferencias. Voy a hacer una transferencia hacia la cuenta de prueba. El agente de Débito valida el saldo y la cuenta destino, actualiza ambos saldos y guarda el movimiento en la base de datos.”

**0:52–1:13**

“En tarjeta de crédito aparecen la línea aprobada, el saldo utilizado, la fecha de corte y la fecha límite de pago. El sistema calcula el pago mínimo y el pago total, y genera una alerta cuando la fecha límite está próxima. También permite registrar compras y pagos.”

**1:13–1:33**

“El módulo de préstamos incluye bancario, hipotecario y vehicular. Capturo monto y plazo, y el sistema calcula una mensualidad estimada. En seguros puedo seleccionar vida, auto, patrimonio para casa o empresa, y médico.”

**1:33–1:50**

“Finalmente, en movimientos recientes se comprueba que las operaciones quedan almacenadas en SQLite. La sección de agentes muestra qué componente procesó cada operación. Con esto se cubren base de datos, diseño, agentes y funcionalidad bancaria.”

**1:50–1:55**

“Este es el funcionamiento completo de BancoFlow para la Práctica 6.”

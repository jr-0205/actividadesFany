# Guion para video — máximo 2 minutos

**0:00–0:15 — Presentación**  
“Esta es NexaTech Store, el prototipo de una empresa que comercializa artículos tecnológicos. El proyecto se desarrolló con Flask, JavaScript y una base de datos SQLite, tomando como base la propuesta previa de IA Agéntica.”

**0:15–0:35 — Catálogo**  
“En el catálogo tenemos ocho productos tecnológicos, con búsqueda, categorías, precio y existencias. Los datos son simulados para fines académicos.”  
Usa un filtro y agrega dos productos al carrito.

**0:35–0:55 — Venta y base de datos**  
“Al registrar una venta, el sistema la guarda en SQLite y descuenta automáticamente las unidades del inventario.”  
Registra la venta y enseña cómo cambian las métricas y el stock.

**0:55–1:15 — Inventario**  
“También existe un módulo de inventario donde se pueden modificar precio y existencias. Al presionar Guardar, el cambio queda persistido en la base de datos.”  
Cambia una existencia y guarda.

**1:15–1:45 — IA Agéntica**  
“El asistente utiliza la estructura propuesta en la práctica anterior. El Orquestador coordina al agente de mercado, catálogo, inventario, ventas y calidad. La recomendación se filtra con el perfil del cliente, su necesidad, presupuesto y el stock real registrado en la base.”  
Ejecuta una recomendación y muestra las cinco etapas.

**1:45–2:00 — Cierre**  
“Así, NexaTech Store integra funcionalidad, buen diseño, base de datos y el enfoque multiagente solicitado. Las decisiones comerciales mostradas son una simulación académica.”
